Methodology

Spoor traced {% if run.direction == "forward" %}forward from the seed, following each address's outgoing{% else %}backward from the seed, following each address's incoming{% endif %} {{ run.token.symbol }} transfers breadth-first, hop by hop, up to {{ run.max_hops }} hop{{ run.max_hops|pluralize }}.

At each address only transfers inside the window and at or above the minimum amount are considered, and only those consistent in time with how funds reached the address: {% if run.direction == "forward" %}outflows at or after its first followed inflow{% else %}inflows at or before its last followed outflow{% endif %}. The {{ run.fan_out }} largest are followed; when more qualify, the address is marked as truncated. Each address is expanded once, so cycles end.

The trace stops at addresses labeled as exchanges, bridges or mixers, where funds leave the traceable on-chain path. Labels come from named datasets with a public source each; sanctioned addresses come from the US Treasury OFAC SDN list. Heuristic signals describe transaction patterns and are not attribution.

Every transfer is parsed from a stored provider response, cited by reference below. Responses are stored byte for byte with their SHA-256; API keys are never stored.
